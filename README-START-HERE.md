# Start here

1. Create an empty folder (for example kanakku-for-google-cloud) and copy everything from this kit into it, including the hidden .agents folder.
2. Run: git init
3. Open the folder in Google Antigravity.
4. Install the Google Developer Knowledge MCP server in Antigravity (MCP Servers panel). The rules ask the agent to check official Google docs before using any API or billing field.
5. Go to Customizations > Rules and confirm the three rules in .agents/rules are loaded and set to Always On.
6. Confirm the workflows show up as slash commands: /new-feature, /security-review, /release-check.
7. Keep the Agent in Planning mode.
8. Start DEMO-SETUP.md in the console today, because billing data takes time to appear.
9. Open PROMPTS.md and paste Phase 0 into the Agent.
10. Before going public, confirm kanakku-for-google-cloud is free on GitHub and "Kanakku for Google Cloud" is free on the Chrome Web Store, and make sure all public descriptions include the independent community project disclaimer and do not imply Google made it.
