Privacy Policy

Last updated: 2026-11-26

Kanakku for Google Cloud is an independent community project and is not affiliated with or endorsed by Google.

Summary

  • No developer servers: Kanakku has no backend servers, no analytics, and no telemetry.
  • Data stays in your browser: Billing data is queried directly from your own Google Cloud BigQuery export to your browser.
  • Read-only: Kanakku never creates, modifies, or deletes Google Cloud resources.

What Kanakku Accesses

  • Chrome permissions: sidePanel, identity (read-only scope https://www.googleapis.com/auth/bigquery.readonly), and storage (for settings and short-lived local cache in chrome.storage.local).
  • Google Cloud Console URLs: Reads only the active https://console.cloud.google.com/* tab URL. Never reads webpage DOM content, form values, or console text.
  • BigQuery API: Queries only your configured daily_resource_costs summary table via https://bigquery.googleapis.com/*.
  • Optional Gemini API: Off by default. Used only if you enable AI explanations and provide your own Gemini API key, sending only the small visible cost summary.

Deleting Your Data

You can clear all saved settings, optional API keys, cached cost summaries, and OAuth tokens at any time using the Clear all data button on the extension's Options page.
