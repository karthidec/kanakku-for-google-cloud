# Open source and brand rules

- License: Apache 2.0.
- The README and anywhere the project is described publicly must say clearly: "Kanakku for Google Cloud is an independent community project and is not affiliated with or endorsed by Google."
- Do not use Google logos or Google product icons.
- The product name must always be "Kanakku for Google Cloud" (full display name: "Kanakku for Google Cloud: price tags for your Google Cloud console") or "Kanakku" (in everyday text; Tamil for "accounts", pronounced KUH-nuk-koo). Never use "gcloud", "Google Cloud Kanakku", or any wording that suggests Google made it.
- The README must always include: what it does in one sentence, a screenshot or short GIF, a 10-minute setup guide, what data it reads and why, known limitations, and how to contribute.
- Keep docs/privacy-policy.md accurate and in plain English. Update it in the same change as any data or permission change.
- Never claim savings numbers that were not measured. Label examples as examples.
- Keep CHANGELOG.md with short dated entries.
