# /release-check

1. Run build, lint, and the full test suite.
2. Run /security-review.
3. Follow docs/setup-guide.md from scratch as a new user would, and report any step that is unclear or broken.
4. Confirm README, privacy policy, CHANGELOG, LICENSE, CONTRIBUTING, and SECURITY files exist and are current.
5. Confirm the Chrome Web Store listing text in docs/store-listing.md matches what the extension really does and permissions it really uses.
6. Give me a pass or fail checklist. Do not tag, publish, or upload anything without my approval.
